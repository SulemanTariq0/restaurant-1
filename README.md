# BirchLight

Standalone responsive food-ordering frontend for the fictional BirchLight brand.

## Run

Open `index.html` directly in a modern browser, or serve this folder with any static HTTP server.

## Included

- Responsive homepage
- Exact supplied BirchLight hero assets
- Product catalog and product detail routes
- Custom product options
- Shared localStorage cart
- Cart drawer
- Checkout preview
- Mobile navigation
- Hash routing
- Responsive CSS
- Accessibility-focused controls

No backend or payment processing is included.
